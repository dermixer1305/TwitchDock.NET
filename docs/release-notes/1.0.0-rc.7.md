# TwitchDock.NET 1.0.0-rc.7

## English

The seventh release candidate of **TwitchDock.NET**, an independent .NET 8 / .NET 10 SDK for the Twitch API, EventSub, chat and authentication. It brings the SDK in line with the rebuilt Twitch API reference (snapshot 2026-11-25). Twitch changed 38 Helix sections; each was reviewed against the SDK. **Some response types change, so code that reads them must be updated.**

### Breaking changes

- **Ads:** `AdSchedule.SnoozeRefreshAt`, `NextAdAt`, `LastAdAt` and `AdSnoozeResult.SnoozeRefreshAt`, `NextAdAt` are `DateTimeOffset?` instead of `string`. Twitch sends Unix timestamps in seconds, which the old string properties could not read. A value of 0 becomes `null`; RFC3339 strings are still accepted. Migration: replace checks such as `NextAdAt == ""` with `NextAdAt is null`.
- **Schedule and videos:** `ScheduleSegment.EndTime` is `DateTimeOffset?` (null when a segment has no duration). `TwitchVideo.PublishedAt` is `DateTimeOffset?` (null for unpublished videos). Schedule segment `Duration` is sent as a JSON number, as the reference now documents.
- **Stream markers:** `StreamMarker.Url` reads the field `URL`, which Twitch actually sends.
- **Guest Star (beta):** Update Channel Guest Star Settings uses `PATCH` instead of `PUT`. `GroupLayout` accepts only `TILED` and `SCREENSHARE`. An update must set a field or `RegenerateBrowserSources = true`. Read and manage operations need the `channel:*:guest_star` scopes when `moderator_id` is the broadcaster and the `moderator:*:guest_star` scopes otherwise. `GuestStarChannelSettings.BrowserSourceToken` is nullable (null for moderators).
- **Stricter request checks:** the suspicious-user methods check that a user token belongs to `moderator_id`. `GetUnbanRequestsAsync` rejects `First` above 100. `ModifyChannelInformationAsync` rejects more than 6 content classification labels and `MatureGame`. `CreateEventSubSubscriptionAsync` requires `IsBatchingEnabled = true` for `drop.entitlement.grant` and rejects it for other types.

### Obsolete

Twitch removed these, and the SDK keeps them as `[Obsolete]` until a major release: `TwitchScopes.WhispersRead` (use `UserReadWhispers` or `UserManageWhispers`); `Before` on `GetClipsRequest`, `GetTopGamesRequest`, `GetBannedUsersRequest` and `GetStreamMarkersRequest`; `TwitchPoll.BitsVotingEnabled`, `BitsPerVote` and `PollChoice.BitsVotes`; `GuestStarUpdateSlotSettingsRequest.Volume`; `GuestStarGuest.AudioSettings`, `VideoSettings` (use the new `Audio` and `Video`), `UserDisplayName` and `UserLogin`. The two deprecated Tags endpoints left the Twitch reference; their obsolete SDK methods remain.

### Added

`EventSubSubscription.IsBatchingEnabled`; `ExtensionViews.LiveConfig` and the component view fields `AspectWidth`, `AspectHeight`, `Size`, `Zoom`, `ZoomPixels`; `GetUserBlockListRequest.UserIds`; additional accepted scopes for Modify Channel Information, Create Stream Marker, Update User Extensions and Get User Block List; several comma-separated video languages; cursors and enumeration for game listings.

All 147 Helix endpoints and 83 EventSub types of the new reference are complete. The release workflow requires the full test matrix, 967 unit and contract tests per target framework, Twitch CLI integration tests, package smoke tests, native AOT checks and the API-coverage gate. Full list: [changelog](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.7/CHANGELOG.md).

This is a **prerelease**. Public APIs may change before 1.0.0.

### Get started

```sh
dotnet add package TwitchDock.DependencyInjection --prerelease
```

## Deutsch

Die siebte Vorabversion von **TwitchDock.NET**, einem unabhängigen SDK für **.NET 8 und .NET 10** mit Twitch-API, EventSub, Chat und Anmeldung. Sie bringt das SDK auf den Stand der neu aufgebauten Twitch-API-Referenz (Stand 25.11.2026). Twitch hat 38 Helix-Abschnitte geändert; jeder wurde gegen das SDK geprüft. **Einige Antworttypen ändern sich. Code, der sie liest, muss angepasst werden.**

### Inkompatible Änderungen

- **Werbung:** `AdSchedule.SnoozeRefreshAt`, `NextAdAt`, `LastAdAt` und `AdSnoozeResult.SnoozeRefreshAt`, `NextAdAt` sind `DateTimeOffset?` statt `string`. Twitch sendet Unix-Zeitstempel in Sekunden, die die alten String-Eigenschaften nicht lesen konnten. Der Wert 0 wird zu `null`; RFC3339-Strings werden weiter akzeptiert. Migration: Prüfungen wie `NextAdAt == ""` durch `NextAdAt is null` ersetzen.
- **Streamplan und Videos:** `ScheduleSegment.EndTime` ist `DateTimeOffset?` (null, wenn ein Segment keine Dauer hat). `TwitchVideo.PublishedAt` ist `DateTimeOffset?` (null bei unveröffentlichten Videos). `Duration` von Streamplan-Segmenten wird als JSON-Zahl gesendet, wie es die Referenz jetzt beschreibt.
- **Stream-Marker:** `StreamMarker.Url` liest das Feld `URL`, das Twitch tatsächlich sendet.
- **Guest Star (Beta):** Update Channel Guest Star Settings nutzt `PATCH` statt `PUT`. `GroupLayout` akzeptiert nur `TILED` und `SCREENSHARE`. Eine Änderung muss ein Feld setzen oder `RegenerateBrowserSources = true`. Lese- und Verwaltungsoperationen brauchen die Scopes `channel:*:guest_star`, wenn `moderator_id` der Broadcaster ist, sonst die Scopes `moderator:*:guest_star`. `GuestStarChannelSettings.BrowserSourceToken` ist nullable (null für Moderatoren).
- **Strengere Prüfungen:** Die Methoden für verdächtige Nutzer prüfen, ob ein User-Token zu `moderator_id` gehört. `GetUnbanRequestsAsync` lehnt `First` über 100 ab. `ModifyChannelInformationAsync` lehnt mehr als 6 Inhaltskennzeichnungen und `MatureGame` ab. `CreateEventSubSubscriptionAsync` verlangt `IsBatchingEnabled = true` für `drop.entitlement.grant` und lehnt es für andere Typen ab.

### Veraltet

Twitch hat Folgendes entfernt. Das SDK behält es bis zu einer Hauptversion als `[Obsolete]`: `TwitchScopes.WhispersRead` (stattdessen `UserReadWhispers` oder `UserManageWhispers`); `Before` bei `GetClipsRequest`, `GetTopGamesRequest`, `GetBannedUsersRequest` und `GetStreamMarkersRequest`; `TwitchPoll.BitsVotingEnabled`, `BitsPerVote` und `PollChoice.BitsVotes`; `GuestStarUpdateSlotSettingsRequest.Volume`; `GuestStarGuest.AudioSettings`, `VideoSettings` (stattdessen die neuen `Audio` und `Video`), `UserDisplayName` und `UserLogin`. Die zwei veralteten Tags-Endpunkte sind aus der Twitch-Referenz verschwunden; ihre veralteten SDK-Methoden bleiben.

### Neu

`EventSubSubscription.IsBatchingEnabled`; `ExtensionViews.LiveConfig` und die Felder `AspectWidth`, `AspectHeight`, `Size`, `Zoom`, `ZoomPixels` der Komponentenansicht; `GetUserBlockListRequest.UserIds`; zusätzlich akzeptierte Scopes für Modify Channel Information, Create Stream Marker, Update User Extensions und Get User Block List; mehrere kommagetrennte Videosprachen; Cursor und Aufzählung für Spielelisten.

Alle 147 Helix-Endpunkte und 83 EventSub-Typen der neuen Referenz sind vollständig. Vor der Freigabe verlangt der Workflow die vollständige Testmatrix, 967 Unit- und Vertragstests pro Zielplattform, Twitch-CLI-Integrationstests, Paketprüfungen, Native AOT und die Prüfung der API-Abdeckung. Vollständige Liste: [Changelog](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.7/CHANGELOG.md).

Dies ist eine **Vorabversion**. Die öffentliche API kann sich vor Version 1.0 noch ändern.
