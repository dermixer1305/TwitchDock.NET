# TwitchDock.NET 1.0.0-rc.4

## English

The fourth release candidate of **TwitchDock.NET**, an independent .NET 8 / .NET 10 SDK for the Twitch API, EventSub, chat and authentication. It fixes problems found in live tests against Twitch. **Updating is recommended for everyone using the EventSub WebSocket client.** There are no breaking changes.

### Fixes

- **EventSub sessions no longer drop and lose notifications.** Twitch sends its keepalive when the `keepalive_timeout_seconds` window ends, so it arrives a few milliseconds after the window. The client waited exactly that long, so it sometimes treated a healthy session as lost, reconnected and lost the notifications in flight, for example chat commands. It now allows 5 seconds for network latency. A 10-minute live run confirmed stable sessions.
- **OAuth errors say why.** Messages now include Twitch's reason, for example `Twitch OAuth request failed with HTTP 400 (missing_client_secret).`
- **Quieter IRC logs during outages.** Each failed reconnect attempt is one warning line with the reason; the stack trace is logged at debug level.
- **Tutorial step 7:** a Confidential app needs its client secret to renew the saved login. The tutorial now asks for it up front, and the bot stops with a clear message when it is missing.

### Live verification

New live checks against the real Twitch services: IRC login, join, receive and send; recovery of both EventSub and IRC after a network outage, including re-created subscriptions; and refresh-token rotation with `FileTokenStore` across restarts. Details and remaining gaps are in the [live-verification report](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.4/docs/live-verification.md).

The release workflow requires the Windows/Linux test matrix, 932 unit/contract tests per target framework, Twitch CLI integration tests, package smoke tests, native AOT checks and the API-coverage gate.

This is a **prerelease**. Public APIs may change before 1.0.0. No independent security audit is claimed.

### Get started

```sh
dotnet add package TwitchDock.DependencyInjection --prerelease
```

Then follow the [English tutorial](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.4/docs/tutorial.md). Upgrading from rc.3 needs no code changes.

## Deutsch

Die vierte Vorabversion von **TwitchDock.NET**, einem unabhängigen SDK für **.NET 8 und .NET 10** mit Twitch-API, EventSub, Chat und Anmeldung. Sie behebt Probleme aus Live-Tests gegen Twitch. **Das Update wird allen empfohlen, die den EventSub-WebSocket-Client nutzen.** Es gibt keine inkompatiblen Änderungen.

### Korrekturen

- **EventSub-Sessions brechen nicht mehr ab und verlieren keine Benachrichtigungen.** Twitch schickt das Keepalive am Ende des Fensters `keepalive_timeout_seconds`, es kommt also ein paar Millisekunden danach an. Der Client hat genau so lange gewartet, hielt deshalb manchmal eine gesunde Session für verloren, verband sich neu und verlor dabei Benachrichtigungen, zum Beispiel Chatbefehle. Jetzt rechnet er 5 Sekunden für die Netzlaufzeit ein. Ein 10-minütiger Live-Lauf bestätigte stabile Sessions.
- **OAuth-Fehler nennen den Grund.** Die Meldungen enthalten jetzt die Ursache von Twitch, zum Beispiel `Twitch OAuth request failed with HTTP 400 (missing_client_secret).`
- **Ruhigere IRC-Logs bei Ausfällen.** Jeder fehlgeschlagene Verbindungsversuch ist eine Warnzeile mit dem Grund; der Stacktrace steht auf der Debug-Ebene.
- **Tutorial-Schritt 7:** Eine vertrauliche App braucht ihr Client-Secret, um die gespeicherte Anmeldung zu erneuern. Das Tutorial fragt es jetzt vorher ab, und der Bot beendet sich mit einer klaren Meldung, wenn es fehlt.

### Live-Prüfung

Neue Live-Tests gegen die echten Twitch-Dienste: IRC-Anmeldung, Kanal betreten, Empfangen und Senden; Wiederherstellung von EventSub und IRC nach einem Netzausfall einschließlich neu angelegter Abos; und der Austausch der Refresh-Tokens mit `FileTokenStore` über Neustarts hinweg. Details und offene Punkte stehen im [Live-Testbericht](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.4/docs/live-verification.md).

Vor der Freigabe verlangt der Workflow erfolgreiche Windows-/Linux-Tests, 932 Unit-/Vertragstests je Zielplattform, Twitch-CLI-Integrationstests, Paketprüfungen, Native AOT und die Prüfung der API-Abdeckung.

Dies ist eine **Vorabversion**. Die öffentliche API kann sich vor Version 1.0 noch ändern. Eine unabhängige Sicherheitsprüfung wird nicht behauptet.

dotnet add package TwitchDock.DependencyInjection --prerelease
