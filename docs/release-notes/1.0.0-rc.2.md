# TwitchDock.NET 1.0.0-rc.2

## English

The second release candidate of **TwitchDock.NET**, an independent .NET 8 / .NET 10 SDK for the Twitch API, EventSub, chat and authentication. It brings no public API changes; it makes the packages easier to find, install and learn.

### What's new

- **On nuget.org.** Install with `dotnet add package TwitchDock.DependencyInjection --prerelease`. Releases are also pushed to GitHub Packages, and every GitHub release still carries the six packages, a zip bundle and SHA-256 checksums.
- **Better package pages.** A package icon, a description per package, more search tags and the new README with runnable examples: chat bot, follow/sub/raid alerts, API calls and ASP.NET Core.
- **"Which package do I need?"** A decision table plus one example per package in the README.
- **Rewritten tutorials** in English and German: create your own project from NuGet, build a chat bot with commands, add alerts, read API data and keep the bot running for hours. No clone or local build required.
- **Dependency updates** within the 8.x line: Microsoft.Extensions.Logging.Abstractions 8.0.3 and Microsoft.Extensions.Http 8.0.1.

### Validation and limits

The release workflow requires the Windows/Linux test matrix, 878 unit/contract tests per target framework, Twitch CLI integration tests, package smoke tests, native AOT checks and the API-coverage gate. The public API snapshots are unchanged from rc.1. All code examples in the README and tutorials were compiled against the published packages. Live verification covers the same selected flows as rc.1; see the [live-verification report](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.2/docs/live-verification.md).

This is a **prerelease**. Broader live verification is still pending; public APIs may change before 1.0.0. No independent security audit is claimed.

### Get started

```sh
dotnet add package TwitchDock.DependencyInjection --prerelease
```

Then follow the [English tutorial](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.2/docs/tutorial.md). Upgrading from rc.1 needs no code changes.

## Deutsch

Die zweite Vorabversion von **TwitchDock.NET**, einem unabhängigen SDK für **.NET 8 und .NET 10** mit Twitch-API, EventSub, Chat und Anmeldung. Die öffentliche API bleibt unverändert; die Pakete sind jetzt leichter zu finden, zu installieren und zu lernen.

### Neu

- **Auf nuget.org.** Installation mit `dotnet add package TwitchDock.DependencyInjection --prerelease`. Releases landen außerdem in GitHub Packages, und jedes GitHub-Release enthält weiterhin die sechs Pakete, ein ZIP und SHA-256-Prüfsummen.
- **Bessere Paketseiten.** Ein Paket-Icon, eine eigene Beschreibung pro Paket, mehr Suchbegriffe und die neue README mit lauffähigen Beispielen: Chatbot, Alerts für Follows, Subs und Raids, API-Abfragen und ASP.NET Core.
- **„Welches Paket brauche ich?“** Eine Entscheidungstabelle und ein Beispiel pro Paket in der README.
- **Neu geschriebene Tutorials** auf Deutsch und Englisch: eigenes Projekt aus NuGet anlegen, Chatbot mit Befehlen bauen, Alerts ergänzen, API-Daten lesen und den Bot stundenlang laufen lassen. Klonen oder lokales Bauen ist nicht nötig.
- **Aktualisierte Abhängigkeiten** innerhalb von 8.x: Microsoft.Extensions.Logging.Abstractions 8.0.3 und Microsoft.Extensions.Http 8.0.1.

### Prüfungen und Grenzen

Vor der Freigabe verlangt der Workflow erfolgreiche Windows-/Linux-Tests, 878 Unit-/Vertragstests je Zielplattform, Twitch-CLI-Integrationstests, Paketprüfungen, Native AOT und die Prüfung der API-Abdeckung. Die Snapshots der öffentlichen API sind gegenüber rc.1 unverändert. Alle Codebeispiele aus README und Tutorials wurden gegen die veröffentlichten Pakete kompiliert. Die Live-Tests umfassen dieselben ausgewählten Abläufe wie bei rc.1; siehe [Live-Testbericht](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.2/docs/live-verification.md).

Dies ist eine **Vorabversion**. Weitere Live-Tests stehen aus, und die öffentliche API kann sich vor Version 1.0 noch ändern. Eine unabhängige Sicherheitsprüfung wird nicht behauptet.

### Einstieg

```sh
dotnet add package TwitchDock.DependencyInjection --prerelease
```

Danach dem [deutschen Tutorial](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.2/docs/tutorial.de.md) folgen. Der Umstieg von rc.1 braucht keine Codeänderungen.
