# TwitchDock.NET 1.0.0-rc.3

## English

The third release candidate of **TwitchDock.NET**, an independent .NET 8 / .NET 10 SDK for the Twitch API, EventSub, chat and authentication. It makes long-running bots easier and replaces hand-typed notice strings with enums. All changes are additions; code written for rc.2 keeps working.

### What's new

- **Sign in once, run permanently.** `FileTokenStore` saves a login to a file and plugs into `RefreshingTokenProvider` as its `persist` callback, so a bot restarts without a new login and keeps every rotated refresh token (Twitch refresh tokens work only once). The file is replaced atomically and is readable only by the current user on Linux and macOS. [Tutorial step 7](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.3/docs/tutorial.md#7-run-the-bot-permanently) now builds a complete bot that signs in once, renews tokens and validates them hourly.
- **Typed EventSub chat notifications.** `ChannelChatNotificationEvent.Kind` returns a `ChatNotificationKind` (`Sub`, `Resub`, `SubGift`, `Raid`, `Announcement`, `WatchStreak` …), and `IsSharedChat` tells whether the details are in the `SharedChat*` property.
- **Typed IRC user notices.** `IrcUserNotice.Kind` returns an `IrcUserNoticeKind`, and `IrcUserNoticeParameters` names the `msg-param-*` tags, for example `TryGetInt32Parameter(IrcUserNoticeParameters.CumulativeMonths, out var months)`.
- Values Twitch adds later map to `Unknown`; `NoticeType` and `MsgId` still hold the original text.

### Validation and limits

The release workflow requires the Windows/Linux test matrix, 931 unit/contract tests per target framework, Twitch CLI integration tests, package smoke tests, native AOT checks and the API-coverage gate. The public API only gained members. All code examples in the README and tutorials compile against this release. Live verification covers the same selected flows as before; `FileTokenStore` with real refresh-token rotation still needs a live run. See the [live-verification report](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.3/docs/live-verification.md).

This is a **prerelease**. Broader live verification is still pending; public APIs may change before 1.0.0. No independent security audit is claimed.

### Get started

```sh
dotnet add package TwitchDock.DependencyInjection --prerelease
```

Then follow the [English tutorial](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.3/docs/tutorial.md). Upgrading from rc.2 needs no code changes.

## Deutsch

Die dritte Vorabversion von **TwitchDock.NET**, einem unabhängigen SDK für **.NET 8 und .NET 10** mit Twitch-API, EventSub, Chat und Anmeldung. Sie macht dauerhaft laufende Bots einfacher und ersetzt von Hand getippte Texte durch Enums. Alle Änderungen sind Ergänzungen; Code für rc.2 funktioniert weiter.

### Neu

- **Einmal anmelden, dauerhaft laufen.** `FileTokenStore` speichert eine Anmeldung in einer Datei und wird als `persist`-Rückruf an `RefreshingTokenProvider` übergeben. Ein Bot startet so ohne neue Anmeldung und behält jedes erneuerte Refresh-Token (Twitch-Refresh-Tokens gelten nur einmal). Die Datei wird in einem Schritt ersetzt und ist unter Linux und macOS nur für den eigenen Benutzer lesbar. [Tutorial-Schritt 7](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.3/docs/tutorial.de.md#7-den-bot-dauerhaft-laufen-lassen) baut jetzt einen vollständigen Bot, der sich einmal anmeldet, Tokens erneuert und stündlich prüft.
- **Typisierte EventSub-Chatbenachrichtigungen.** `ChannelChatNotificationEvent.Kind` liefert ein `ChatNotificationKind` (`Sub`, `Resub`, `SubGift`, `Raid`, `Announcement`, `WatchStreak` …), und `IsSharedChat` zeigt, ob die Details in der `SharedChat*`-Eigenschaft stehen.
- **Typisierte IRC-Benachrichtigungen.** `IrcUserNotice.Kind` liefert ein `IrcUserNoticeKind`, und `IrcUserNoticeParameters` benennt die `msg-param-*`-Tags, zum Beispiel `TryGetInt32Parameter(IrcUserNoticeParameters.CumulativeMonths, out var months)`.
- Werte, die Twitch später ergänzt, werden zu `Unknown`; `NoticeType` und `MsgId` enthalten weiterhin den Originaltext.

### Prüfungen und Grenzen

Vor der Freigabe verlangt der Workflow erfolgreiche Windows-/Linux-Tests, 931 Unit-/Vertragstests je Zielplattform, Twitch-CLI-Integrationstests, Paketprüfungen, Native AOT und die Prüfung der API-Abdeckung. Die öffentliche API hat nur Mitglieder hinzugewonnen. Alle Codebeispiele aus README und Tutorials kompilieren gegen dieses Release. Die Live-Tests umfassen dieselben ausgewählten Abläufe wie bisher; `FileTokenStore` mit echtem Austausch der Refresh-Tokens braucht noch einen Live-Test. Siehe [Live-Testbericht](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.3/docs/live-verification.md).

Dies ist eine **Vorabversion**. Weitere Live-Tests stehen aus, und die öffentliche API kann sich vor Version 1.0 noch ändern. Eine unabhängige Sicherheitsprüfung wird nicht behauptet.
