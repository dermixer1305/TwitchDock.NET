# TwitchDock.NET 1.0.0-rc.1

## English

The first public release candidate of **TwitchDock.NET**, an independent .NET 8 / .NET 10 SDK for the Twitch API, EventSub, chat and authentication.

### Included

- Six modular packages: Core, Authentication, Helix, EventSub, Chat and DependencyInjection.
- Typed coverage of 149 Helix endpoints and 83 EventSub type/version combinations in the pinned 2026-10-09 documentation, including clearly marked beta and deprecated APIs.
- OAuth/device login, OpenID Connect, token refresh and validation; EventSub WebSockets and verified webhooks; EventSub/Helix chat and IRC.
- Async APIs, cancellation, local authorization checks, source-generated JSON, trimming and native AOT support.
- English and German project guides and beginner tutorials. The chat sample can obtain a user token through an interactive Twitch login and defaults to your own channel.

### Validation and limits

The release workflow requires the Windows/Linux test matrix, 878 unit/contract tests per target framework, Twitch CLI integration tests, package smoke tests, native AOT checks and the API-coverage gate. Selected live tests also passed: app tokens and Helix reads on .NET 8 and .NET 10, and user authorization plus real chat reception and delivery. See the [live-verification report](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.1/docs/live-verification.md) for exact scope and remaining work.

This is a **prerelease**. Broader live verification is still pending; public APIs may change before 1.0.0. No independent security audit is claimed.

### Get started

1. Download **all six `.nupkg` assets** below into one local package folder. `SHA256SUMS.txt` contains their checksums. These packages are not published on nuget.org yet.
2. Register the folder as a local NuGet source and install `TwitchDock.DependencyInjection` version `1.0.0-rc.1`, or build from the source tag.
3. Follow the [English tutorial](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.1/docs/tutorial.md).

Earlier unpublished builds used `TwitchSdk.*`; update project references, namespaces and `AddTwitchSdk` to `TwitchDock.*` and `AddTwitchDock`. The live-test and snapshot environment flags now start with `TWITCHDOCK_`. See the [changelog](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.1/CHANGELOG.md) for other pre-release API changes.

## Deutsch

Die erste öffentliche Vorabversion von **TwitchDock.NET**: ein unabhängiges SDK für **.NET 8 und .NET 10** mit Twitch-API, EventSub, Chat und Anmeldung.

### Enthalten

- Sechs Pakete für Core, Authentication, Helix, EventSub, Chat und Dependency Injection.
- Typisierte Abdeckung von 149 Helix-Endpunkten und 83 EventSub-Typ-/Versionskombinationen gemäß dem Dokumentationsstand vom 09.10.2026; Beta- und veraltete APIs sind gekennzeichnet.
- OAuth und Geräteanmeldung, OpenID Connect, Token-Erneuerung und -Prüfung, EventSub über WebSocket und Webhooks sowie Chat über Helix/EventSub und IRC.
- Asynchrone Aufrufe, Berechtigungsprüfungen, quellgeneriertes JSON sowie Trimming und Native AOT.
- Deutsche und englische Projektübersicht und Einsteigertutorials. Das Chatbeispiel erzeugt den Twitch-Anmeldelink selbst und verbindet sich standardmäßig mit deinem Kanal.

### Prüfungen und Grenzen

Vor der Freigabe verlangt der Workflow erfolgreiche Windows-/Linux-Tests, 878 Unit-/Vertragstests je Zielplattform, Twitch-CLI-Integrationstests, Paketprüfungen, Native AOT und die Prüfung der API-Abdeckung. Ausgewählte Live-Tests für App-Tokens, API-Abfragen, Benutzerfreigabe sowie echten Chat-Empfang und -Versand wurden ebenfalls bestanden. Den genauen Umfang beschreibt der [Live-Testbericht](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.1/docs/live-verification.md).

Dies ist eine **Vorabversion**. Weitere Live-Tests stehen aus, und die öffentliche API kann sich vor Version 1.0 noch ändern. Eine unabhängige Sicherheitsprüfung wird nicht behauptet.

### Einstieg

1. Lade **alle sechs `.nupkg`-Dateien** unten in einen gemeinsamen Ordner. Die Prüfsummen stehen in `SHA256SUMS.txt`. Die Pakete liegen noch nicht auf nuget.org.
2. Registriere den Ordner als lokale NuGet-Quelle und installiere `TwitchDock.DependencyInjection` in Version `1.0.0-rc.1`, oder baue den Quellcode des Tags selbst.
3. Folge dem [deutschen Tutorial](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.1/docs/tutorial.de.md).

Bei früheren unveröffentlichten Builds ersetze `TwitchSdk.*` durch `TwitchDock.*` und `AddTwitchSdk` durch `AddTwitchDock`. Umgebungsvariablen für Live-Tests und API-Snapshots beginnen jetzt mit `TWITCHDOCK_`. Weitere Änderungen stehen im [Changelog](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.1/CHANGELOG.md).
