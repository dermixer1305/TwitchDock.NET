# TwitchDock.NET 1.0.0-rc.5

## English

The fifth release candidate of **TwitchDock.NET**, an independent .NET 8 / .NET 10 SDK for the Twitch API, EventSub, chat and authentication. It follows a review of every claim in [SECURITY.md](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.5/SECURITY.md) against the code. There are no breaking changes.

### Security

- **OAuth error responses are filtered completely.** The `error` field of a Twitch OAuth error response is now reduced to known HTTP status phrases and RFC 6749 error codes before it reaches `TwitchApiException.Error` or the exception message, as the `message` field already was. Unknown text, which could echo request data, is dropped. Twitch normally sends harmless values such as `Bad Request`; the change makes the documented guarantee hold in every case.
- **SECURITY.md** now also describes `FileTokenStore` (atomic, user-only file permissions on Linux and macOS, not encrypted), what the SDK logs, and how releases are protected (trusted publishing, reserved `TwitchDock.*` prefix, pinned actions, checksums).

The review confirmed the other claims: credential redaction, tokens only in headers and only to the configured Twitch hosts, loopback-only plain endpoints, webhook signature checks, OAuth state and OpenID Connect validation, and the resource limits. No known vulnerable dependencies were found. This is not an independent security audit.

### Live verification

Since rc.4, webhook delivery was verified live through a public tunnel: verification challenge, signed `channel.update` notification and subscription cleanup. See the [live-verification report](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.5/docs/live-verification.md). The release workflow requires the full test matrix, 932 unit/contract tests per target framework, Twitch CLI integration tests, package smoke tests, native AOT checks and the API-coverage gate.

This is a **prerelease**. Public APIs may change before 1.0.0.

### Get started

```sh
dotnet add package TwitchDock.DependencyInjection --prerelease
```

Then follow the [English tutorial](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.5/docs/tutorial.md). Upgrading from rc.4 needs no code changes.

## Deutsch

Die fünfte Vorabversion von **TwitchDock.NET**, einem unabhängigen SDK für **.NET 8 und .NET 10** mit Twitch-API, EventSub, Chat und Anmeldung. Sie folgt auf eine Prüfung aller Aussagen in [SECURITY.md](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.5/SECURITY.md) am Code. Es gibt keine inkompatiblen Änderungen.

### Sicherheit

- **OAuth-Fehlerantworten werden vollständig gefiltert.** Das Feld `error` einer OAuth-Fehlerantwort von Twitch wird jetzt auf bekannte HTTP-Statustexte und RFC-6749-Fehlercodes reduziert, bevor es in `TwitchApiException.Error` oder die Fehlermeldung gelangt, so wie das Feld `message` schon zuvor. Unbekannter Text, der Anfragedaten wiedergeben könnte, wird verworfen. Twitch schickt dort normalerweise harmlose Werte wie `Bad Request`; die Änderung sorgt dafür, dass die dokumentierte Zusage in jedem Fall gilt.
- **SECURITY.md** beschreibt jetzt auch `FileTokenStore` (sicheres Ersetzen, Dateirechte nur für den eigenen Benutzer unter Linux und macOS, keine Verschlüsselung), was das SDK protokolliert und wie Releases abgesichert sind (Trusted Publishing, reserviertes Präfix `TwitchDock.*`, gepinnte Actions, Prüfsummen).

Die übrigen Aussagen wurden bestätigt: Zugangsdaten in `ToString()` verborgen, Tokens nur im Header und nur an die konfigurierten Twitch-Hosts, unverschlüsselte Endpunkte nur für die eigene Maschine, Webhook-Signaturprüfung, OAuth-State- und OpenID-Connect-Prüfung sowie die Größenlimits. Bekannte anfällige Abhängigkeiten wurden nicht gefunden. Dies ist kein unabhängiges Sicherheitsaudit.

### Live-Prüfung

Seit rc.4 wurde die Webhook-Zustellung über einen öffentlichen Tunnel live geprüft: Prüfanfrage, signierte `channel.update`-Benachrichtigung und Löschen des Abos. Siehe [Live-Testbericht](https://github.com/dermixer1305/TwitchDock.NET/blob/v1.0.0-rc.5/docs/live-verification.md). Vor der Freigabe verlangt der Workflow die vollständige Testmatrix, 932 Unit-/Vertragstests je Zielplattform, Twitch-CLI-Integrationstests, Paketprüfungen, Native AOT und die Prüfung der API-Abdeckung.

Dies ist eine **Vorabversion**. Die öffentliche API kann sich vor Version 1.0 noch ändern.

### Einstieg

```sh
dotnet add package TwitchDock.DependencyInjection --prerelease
```
